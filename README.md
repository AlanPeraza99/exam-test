# WordPress Template

Custom WordPress template.

## Requirements
- WordPress 6.x+
- PHP 8.0+

## Installation
1. Copy the theme folder into:
   `/wp-content/themes/`
2. Go to **Appearance → Themes**.
3. Activate the theme.

## Configuration
- Customize the content from **Appearance → Customize**.
- The theme includes default values.

## Notes
- Uses Tailwind CSS via CDN.
- No additional plugins required.
