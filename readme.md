# Plantilla de WordPress

Plantilla personalizada de WordPress.

## Requisitos

- WordPress 6.x+
- PHP 8.0+

## Instalación

1. Copia la carpeta del tema en:
   `/wp-content/themes/`
2. Ve a **Apariencia → Temas**.
3. Activa la plantilla.

## Configuración

- Personaliza el contenido desde desde admin.
- El tema incluye valores por defecto.

## Notas

- Usa Tailwind CSS vía CDN.
